# Code of conduct

This is a small project with one maintainer, so this is short.

Be civil. Assume the person on the other side is trying to help. Criticise the
code rather than the person who wrote it. Don't post anyone's private
information, including calendar contents that aren't yours.

If someone is making this an unpleasant place to be, tell the maintainer
([@islerfab](https://github.com/islerfab)). Issues, comments and pull requests
that don't belong here get removed, and people who insist get blocked. That's
the whole enforcement mechanism, and it's proportionate to the size of this.

If meridian ever grows a community large enough that this feels inadequate,
the [Contributor Covenant](https://www.contributor-covenant.org/) is the
obvious thing to adopt and this file should be replaced with it.
